# Siplicity

Makes transferring digital files simple.

# Build instructions
## Dependencies
- Flutter
- Golang
- [`buf`](https://buf.build/product/cli)

## Code Generation

### GRPC/Protbuf

Rebuild protobuf and grpc generated files with `buf generate`

### Riverpod code generation

Rebuild code generated by riverpod annotations with (from /frontend directory) `dart run build_runner build`

## Frontend

From /frontend directory, run `flutter build windows`

## Backend

From /backend directory, run `go install github.com/sipli-city/siplicity/siplicityServer`

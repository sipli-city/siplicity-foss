# Siplicity

Makes transferring digital files simple.

# Build instructions
## Dependencies
- Flutter
- Golang
- [`buf`](https://buf.build/product/cli)

## Code Generation

### GRPC/Protbuf

Rebuild protobuf and grpc generated files with `buf generate`

### Riverpod code generation

Rebuild code generated by riverpod annotations with `dart run build_runner build`

## Frontend

Run `flutter build windows`

## Backend

Run `go build github.com/sipli-city/siplicity/server -o siplicityServer.exe`
